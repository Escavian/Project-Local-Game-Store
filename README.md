# Local Game Store Website

A multi‑page HTML/CSS website created to showcase a fictional **Local Game Store**.  
This project demonstrates front‑end development skills including page layout, navigation menus, product listings, images, semantic HTML, and organized site structure.

The site includes pages for board games, trading card games, tabletop RPGs, accessories, events, community involvement, store hours, and contact information.

---

## 📌 Features

- Multi‑page website with consistent navigation  
- Product category pages (Board Games, TCG, RPG, Accessories)  
- Clean layout using external CSS  
- Images and descriptions for each product  
- Events and community pages  
- Contact form with JavaScript validation (if included)  
- Organized folder structure for easy maintenance  
- Fully responsive layout (if your CSS includes media queries)
